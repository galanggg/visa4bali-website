## Fix 3B — Dynamic copyright year (currently hardcoded "© 2024")

Footer shows `© 2024` in 2026 — reads as unmaintained/lower-trust to both users and AI engines (recency is a citation factor).

**Where:** Elementor footer template (Templates → Theme Builder → Footer), a Site Settings footer field, or `footer.php`. The `2024` is almost certainly typed as literal text in the Elementor footer widget.

**Best fix — auto-updating year (never stale again):**

- **Elementor:** replace the text widget's `© 2024 Visa4Bali` with a shortcode. Install a tiny shortcode (Code Snippets plugin) and use `© [current_year] Visa4Bali`:

```php
// Code Snippets plugin — run everywhere. Outputs the current year.
add_shortcode( 'current_year', function () {
    return date( 'Y' );
} );
```

- **Or theme `footer.php`** — replace the literal year with:

```php
&copy; <?php echo esc_html( date( 'Y' ) ); ?> Visa4Bali. All rights reserved.
```

**Quick fix (if you can't add code):** just edit the Elementor footer text `2024` → `2026`. Works now but goes stale again in January — the shortcode is better.
