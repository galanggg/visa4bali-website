# UI / Visual Bugs — visa4bali.com

Audited 2026-05-28 via Chrome DevTools. Tested at desktop 1366×900 and mobile 375×812.
Pages crawled: `/`, `/about-us/`, `/our-services/`, `/contact-us/`, `/shop/`, `/privacy-policy/`.

Severity: 🔴 breaks layout/UX · 🟠 visible flaw · 🟡 polish.

---

## 🔴 Site-wide — Mini-cart header pushes past viewport (mobile)

Pages affected: `/our-services/` confirmed; likely all pages with cart icon.
At 500px viewport: `.elementor-menu-cart__toggle_wrapper` extends to right=505 (viewport=500). Causes 5px horizontal scroll.
**Cause:** Cart toggle button absolute/flex positioning ignores parent padding.
**Fix:** In Elementor header → cart widget → mobile-responsive padding, or CSS:
```css
@media (max-width:767px){
  .elementor-menu-cart__toggle_wrapper{max-width:calc(100vw - 30px);overflow:hidden}
}
```

## 🔴 Homepage — "To travel to Bali" heading busts mobile viewport

H2 `.elementor-element-a3ec264` with text "To travel to Bali" renders 750px wide on a 500px viewport (`font-size:48px` hardcoded, no responsive override).
Causes mobile horizontal scroll (`docW=505 vs winW=500`).
**Fix:** Elementor → that heading widget → Style → Typography → set mobile font-size (e.g. 28-32px) and remove fixed width.

## 🔴 Contact Us page — Zero contact methods on page

`/contact-us/` has:
- 0 `<form>` elements (MetForm class present but no form rendered)
- 0 `mailto:` links
- 0 `tel:` links
- 0 WhatsApp / `wa.me` links
- Only 2 Google Maps iframes
**Impact:** "Don't Hesitate to Contact Us" headline but visitor has no clickable contact action.
**Fix:** Add WhatsApp CTA + working contact form (MetForm) + clickable email/phone.

## 🔴 Privacy Policy — WordPress default placeholder, never customized

`/privacy-policy/` body still contains literal `"suggested text:"` strings — WP boilerplate generated by default privacy policy generator, never replaced. Mentions Gravatar/Akismet (not used here). Zero mention of passport data, visa application data, immigration records, or data retention for VFS submissions.
**Impact:** Site collects **passport scans + personal data** via MetForm. Boilerplate policy is legally inadequate (Indonesia PDP Law + EU GDPR if RU/DE clients).
**Fix:** Replace with custom policy covering: passport image storage, retention, third-party sharing (immigration), data subject rights, contact for data requests.

## ~~🟠 Services / Shop / Privacy — Two H1 tags~~ — RESOLVED 2026-05-30

Root cause: Hello-Elementor theme `header.php` rendered `<h1 class="site-title">` on non-Canvas pages. Filter `hello_elementor_header_site_title_tag` available only in newer theme versions.

**Fix applied:**
1. Updated Hello-Elementor theme to latest.
2. Added Code Snippet (PHP, run everywhere):
   ```php
   add_filter( 'hello_elementor_header_site_title_tag', function() {
       return 'div';
   } );
   ```
3. Cleared WP Rocket cache.

Verified: all 6 pages now show H1 count = 1.

## 🟠 Shop page — only 2 products/page

"Showing 1–2 of 12 results" → 6 pages of pagination for 12 products. Excessive friction.
**Fix:** WooCommerce → Settings → Products → Display → set "Products per row" and "Rows per page" to show 9–12 per page.

## 🟠 About Us — Desktop image overflow

10 elements on `/about-us/` extend past viewport edge (right=1416 vs winW=1366). All `img.wp-image-40` (510px wide) + their `.elementor-widget-container` wrappers.
Visible as image cropping or content peeking past right edge.
**Fix:** Inspect those image widgets in Elementor; remove fixed pixel widths or add `max-width:100%`.

## 🟠 About Us — 20 empty headings + 46 images missing alt

- 20 `<h1..h6>` tags with empty text content (Elementor heading widgets used as spacers).
- 46 `<img>` missing alt attribute.
**Fix:** Replace empty heading widgets with Spacer widget. Add alt text to all content images.

## 🟠 Homepage — Tap targets too small on mobile

Multiple links < 24px tall on 375px viewport:
- "Watch Intro" link: 104×12
- "Service Detail" links (3×): 139×15
- FAQ "How to extend my Visa?" / "How to solve overstay problems": 400×23
- Footer menu items "About", "Visa", "Coaching", "Pricing": 383×21

Apple/Google guideline: min 44×44 (iOS), 48×48 (Android).
**Fix:** Increase padding on these links via Elementor mobile typography / spacing.

4 sections/containers `display:none` or `visibility:hidden` but containing 20+ chars of text. Old Elementor revisions/duplicate widgets left hidden.

## 🟡 Homepage — Cart shows "Rp0" on empty cart

Header mini-cart toggle text reads `"Rp0\n\t\t\t0\n\tCart"` when cart empty. Visible "Rp0" on every page looks like a price tag.
**Fix:** Hide total amount when cart empty, or change to icon-only cart on empty state. WooCommerce template override or Elementor cart widget setting.

## 🟡 All pages — Brand inconsistency ("Visa4Bali Luwuk" appears as H1)

H1 "Visa4Bali Luwuk" appears on `/our-services/`, `/shop/`, `/privacy-policy/`. Site title elsewhere is just "Visa4Bali". Inconsistent brand string + "Luwuk" (a city in Sulawesi) confuses for Bali-focused site.
**Fix:** Decide canonical brand. If H1 is theme/Elementor template (hello-elementor page title), edit single template.

## 🟡 Privacy Policy + Shop + Services — Hello-Elementor default page-title H1

The "Visa4Bali Luwuk" H1 appearing at top of these three pages is likely the hello-elementor theme's page header. Either:
- Customize this template to use the page's own title only, or
- Disable theme page-title block in Hello-Elementor settings.

## 🟡 Homepage — Footer menu text reads `Jki-facebook-f` for social icon

Social icon labels exposing icon-font class names: "Jki-facebook-f" instead of "Facebook". Hurts screen-readers + crawler.
**Fix:** Replace icon widget labels with proper text or use aria-label "Facebook" / hide visually.
