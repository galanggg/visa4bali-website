## Workflow

1. WP Admin → Media → Library → switch to List view (right-side icon)
2. Find filename — Ctrl+F or use search box
3. Click filename → edit screen
4. Paste alt into **Alt Text** field
5. Click **Update**
6. Back arrow → next image

OR faster — open first image, then use **← / → arrow keys** at top of edit screen to navigate library.
